# 🌐 Debargha Mandal - Personal Portfolio

A modern, interactive personal portfolio website showcasing my projects, technical skills, and development experience. Built with React, TypeScript, Vite, Tailwind CSS, Three.js, and GSAP.

## ✨ Features

- **Interactive 3D Visuals**: Dynamic 3D canvas and particle effects powered by Three.js and `@react-three/fiber`
- **Fluid Animations**: Smooth scrolling, micro-interactions, and kinetic typography orchestrated with GSAP and ScrollTrigger
- **Modern Responsive Design**: Built with Tailwind CSS and Radix UI primitives for an accessible, futuristic aesthetic
- **Comprehensive Sections**:
  - Hero with kinetic typography and 3D visualizers
  - About Me & Background
  - Categorized Tech Stack & Development Expertise
  - Featured Projects with live demos and code links
  - Education & Certifications
  - Interactive Contact Section & Social Links

## 🛠️ Tech Stack

- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS
- **Animation & 3D**: GSAP, ScrollTrigger, Three.js, `@react-three/fiber`, `@react-three/drei`
- **UI Components**: Radix UI, Lucide Icons, Phosphor Icons
- **State & Utilities**: TanStack React Query, React Router, clsx, tailwind-merge

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Debargha-Mandal/Debargha-Personal-Portfolio.git
   cd Debargha-Personal-Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
